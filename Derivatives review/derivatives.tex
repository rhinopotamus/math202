\textbf{Instructions:} 
In this Problem Set, you'll carefully solve one of these differentiation problems, then make a purposeful mistake somewhere. Follow these steps:
\begin{enumerate}[(a)]
	\item Choose one of the problems below.
	\item Refer to the list on the next page to identify \textbf{all} the derivative rules you're going to need to use for your problem.
	\item Carefully find the derivative \textbf{step by step}, write out \textbf{every step}, and list all the rules you used in each step. Please see the example on the next page to see how detailed your steps should be.
	\item Choose a \textbf{second} problem, and do the same things, but make your answer wrong somehow. Bonus points\footnote{Points don't exist.} for an error you think people probably make in real life.
\end{enumerate}
Throughout, carefully label any derivative you find by name, using correct derivative notation.

\textbf{(Example)} Find $\dfrac{dp}{dt}$ if 
$p(t) = \dfrac{\cos(t^2-1)}{e^{-3t}}$.

\vspace{1em}

I am going to need the following derivative rules:
\begin{multicols}{3}
	\begin{itemize}
		\item quotient rule
		\item trig function rule
		\item chain rule
		\item power rule
		\item sum rule
		\item constant function rule
		\item exponential function rule
		\item constant multiple rule
		\item[]
	\end{itemize}
\end{multicols}
Now I will find the derivative, step by step, and 
explain what rules I am using in every step:
\begin{align*}
\frac{dp}{dt} &= \frac{[e^{-3t}] [\cos(t^2-1)]' - 
					   [e^{-3t}]'[\cos(t^2-1)]}
					  {[e^{-3t}]^2}
& \textrm{(quotient rule)} \\ \\
&= \frac{[e^{-3t}] [\cos(t^2-1)]' - 
		 [e^{-3t}\cdot(-3)][\cos(t^2-1)]}
		{[e^{-3t}]^2} 
& \textrm{(chain rule, exp. function rule,} \\
& &\textrm{ power rule, constant multiple rule)} \\ \\
&= \frac{[e^{-3t}] [-\sin(t^2-1)\cdot(2t)] - 
		 [e^{-3t}\cdot(-3)][\cos(t^2-1)]}
		{[e^{-3t}]^2}
& \textrm{(chain rule, trig function rule,} \\
&&\textrm{ power rule, sum rule,}\\
&&\textrm{constant function rule)}
\end{align*}

\hrulefill

Here is a list of some derivative shortcut rules from Calculus 1. Feel free to keep this for reference.
    \begin{itemize}
        \item sum rule: $\diff{x}[f(x)+g(x)] = \diff{x}[f(x)]+\diff{x}[g(x)]$ 
        \item constant multiple rule: $\diff{x}[c\cdot f(x)] = c\cdot\diff{x}[f(x)]$
        \item constant function rule: $\diff{x}[c] = 0$
        \item power rule: $\diff{x}[x^n] = nx^{n-1}$
        \item exponential function rule: $\diff{x}[a^x] = a^x\cdot\ln(a)$
        \item trigonometric function rules: $\diff{x}[\sin(x)] = \cos(x)$; $\diff{x}[\cos(x)] = -\sin(x)$; $\diff{x}[\tan(x)] = \sec^2(x)$
        \item product rule: $\diff{x}[f(x) \cdot g(x)] = \diff{x}[f(x)] \cdot g(x) + \diff{x}[g(x)] \cdot f(x)$
        \item quotient rule: $\displaystyle \diff{x}\left[\frac{f(x)}{g(x)}\right] 
        = \frac{g(x) \cdot \diff{x}[f(x)] - f(x) \cdot \diff{x}[g(x)]}{[g(x)]^2}$
        \item chain rule: $[f(g(x))]' = f'(g(x)) \cdot g'(x)$
        \item logarithmic function rule: $\displaystyle \diff{x}[\ln(x)] = \frac{1}{x}$
        %\item inverse trig function rules: $\displaystyle \diff{x}[\arctan(x)] = \frac{1}{1+x^2}$;
        %$\displaystyle \diff{x}[\arcsin(x)] = \frac{1}{\sqrt{1-x^2}}$
    \end{itemize}
