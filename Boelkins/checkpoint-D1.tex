\section{Learning target D1, version 1}

Check whether a function is a solution to a differential equation, and explain why the function is or is not a solution.

\hrulefill

Consider the differential equation

\[ \dfrac{dh}{dt} = -2 \sqrt{h}.
\]

Check whether each of the following is or is not a solution. 
\begin{enumerate}
	\item $h(t) = t^2 + 4t + 4$ (Hint: Factor.)
	\vfill
	\item $h(t) = (10 - t)^2$
	\vfill
	\item $h(t) = 4e^{2t}$
	\vfill
\end{enumerate}
