\section{Learning target D1, version 1}

Check whether a function is a solution to a differential equation, and explain why the function is or is not a solution.

\hrulefill

Consider the differential equation

\[ \dfrac{dh}{dt} = -2 \sqrt{h}.
\]

Check whether each of the following is or is not a solution. 
\begin{enumerate}
	\item $h(t) = t^2 + 4t + 4$ (Hint: Factor.)
	\vfill
	\item $h(t) = (10 - t)^2$
	\vfill
	\item $h(t) = 4e^{2t}$
	\vfill
\end{enumerate}

\section{Learning target D1, version 2}

Check whether a function is a solution to a differential equation, and explain why the function is or is not a solution.

\hrulefill

Consider the differential equation

\[\dfrac{dT}{dt} = -k \cdot(T-73),
\]
where $k>0$ is some constant. Check whether each of the following is or is not a solution: 
\begin{enumerate}[(a)]
	\item $T(t) = 73$
	\vfill
	\item $T(t) = 38 e^{-kt}$
	\vfill
	\item $T(t) = 73+47e^{-kt}$
	\vfill
\end{enumerate}
