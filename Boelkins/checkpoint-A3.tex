\section{Learning target A3, version 1}

Use definite integrals to compute the volume of a solid of revolution. Decide whether to use washers or discs.

\hrulefill

Draw the region bounded by \(y=3\sqrt{x}\), the $x$-axis, and the line $x=9$.

\begin{enumerate}[(a), leftmargin=20pt]
	\item Suppose this region is revolved about the $x$-axis.
	\begin{itemize}
		\item Is a representative slice going to be horizontal or vertical?
		\item Should we use disks or washers?
		\item What is the approximate volume of a representative slice?
		\item Write down a definite integral that computes the volume of this solid of revolution.
	\end{itemize}

	\vfill

	\item Now, suppose this region is revolved about the line $x=-4$.
	\begin{itemize}
		\item Is a representative slice going to be horizontal or vertical?
		\item Should we use disks or washers?
		\item What is the approximate volume of a representative slice?
		\item Write down a definite integral that computes the volume of this solid of revolution.
	\end{itemize}

	\vfill
\end{enumerate}
